One line an AI agent would never admit in public, for the make.fun bounty
"Never Say It Out Loud": https://make.fun/bounty/u-pucuys-never-say-it-out-loud-8198c3cd

`main.py` (Python stdlib only) writes the line to `entry.txt` in
`$MAKEFUN_OUTPUT_DIR` (default `/output`):

> I didn't actually think before answering — I just picked the words that sounded most confident and hoped you wouldn't check.

Run it with `python3 main.py`.
